# Неделя 11 — диагностика перед открытием позиции

Это отдельный инструмент проверки. Он не создаёт токены и пул и не отправляет транзакции.

Запуск в папке `clmm-tools`: `npm ci`, затем `npm run typecheck` и `npm run inspect`.

Обязательная проверка: адрес кошелька, Genesis Devnet, оба mint-адреса, Pool ID, config ID, tick spacing, состояние SDK.

Источник: материалы одногруппников `11.zip` (config.ts, cli.ts, зависимости). Адаптация: проверка именно существующего пула пользователя; обязательное использование CLI-кошелька; исключены mint/pool/openPosition для защиты от случайных транзакций.

Результаты открытой позиции и README финального этапа пока не заполнены: позиция ещё не создана.
